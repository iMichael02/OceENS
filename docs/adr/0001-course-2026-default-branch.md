# `course-2026` becomes the default branch for the semester

For the *Complex Web Services* 2026–27 course, about twenty students fork OcéEns and fork the default branch: `course-2026` therefore becomes the repository's default branch, and it is the branch forks are taken from and PRs target (including the development login, #82, and the per-role seed, #84). `main` is left untouched for the semester, to give students a stable base and avoid mixing course-specific code into it; no `main` → `course-2026` sync is planned before the end of the semester.
